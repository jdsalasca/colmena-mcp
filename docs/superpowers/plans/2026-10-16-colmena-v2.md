# colmena-mcp v0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline). Steps use checkbox syntax.

**Goal:** Multi-provider (Codex + OpenCode) orchestration MCP with YAML config, budget routing, Windows toast notifications, and HTML report generation (papercraft).

**Architecture:** Adapters normalize provider CLIs to one event model; `JobManager` resolves a worker alias → adapter; plugins subscribe to a small event bus; ledger tracks cost per worker.

**Tech Stack:** Node 24 ESM, `@modelcontextprotocol/sdk`, `zod`, `yaml`, `node:test`.

**Spec:** `docs/superpowers/specs/2026-10-16-colmena-v2-design.md`

## Global Constraints
- Tools never accept a free model/flag; only a worker alias from `colmena.yml`.
- Env: `COLMENA_*` preferred, `LUNA_*` legacy alias (`HOME`, `CODEX_BIN`, `MAX_PARALLEL`, `JOB_TIMEOUT_MIN`). Default home `~/.colmena`.
- `.js` bin paths (fakes) run via `process.execPath`.
- Existing v0.1 behavior (isolation, merge, cleanup guard) must keep passing.
- Windows toast through `powershell.exe` 5.1; tests use `COLMENA_NOTIFIER=log|none` or injected notifier.

## Review Focus
- Invalid/missing `colmena.yml` → clear error naming the field; absent file → defaults.
- Worker alias unknown / disabled / over budget → actionable error, never a silent fallback.
- OpenCode text with multiple `text` parts → last one is the final message.
- Heartbeat never fires with zero jobs and never keeps the process alive.
- Report with a failed reporter job → fallback HTML still produced, `usedFallback:true`.
- Paths with spaces/accents for report folder and `open`.
